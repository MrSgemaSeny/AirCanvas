# Air Canvas

Рисуй в воздухе перед вебкамерой с помощью жестов рук.

## Жесты
- **Указательный палец** — рисовать
- **Два пальца** — пауза (поднять перо)
- **Кулак** — очистить холст

## Запуск

### Backend
```bash
cd backend
uv run uvicorn main:app --port 8002
```

### Frontend
```bash
cd frontend
npm run dev
```

Открыть: http://localhost:5174
